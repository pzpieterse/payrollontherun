## How to Use

1. **Branding** – Follow the colour and logo guidelines so the website matches the Play Store app icon (green + motion).
2. **Logo** – Replace the placeholder “PR” icon boxes in the HTML with the real green app icon PNG/SVG from Play Store.
3. **Screenshots** – Add real phone mockups from the Play Store listing into the hero and landing page for higher conversion.
4. **Upload**
   - `index.html` → your main domain root
   - `get-started.html` → `/get-started` (or rename to `/download`)
5. **Facebook Ads** – Point all campaigns to the `/get-started` page. Use the provided copy variations.
